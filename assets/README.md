# `assets/` — The Brand Kit

The DIAD logo assets, in a few sizes and color variants:

- `diad-logo-white.png` / `diad-logo-white-4x.png` — light logo (for dark backgrounds)
- `diad-logo-black.png` / `diad-logo-black-4x.png` — dark logo (for light backgrounds)

The `4x` versions are higher resolution for crisp display on HiDPI screens.
